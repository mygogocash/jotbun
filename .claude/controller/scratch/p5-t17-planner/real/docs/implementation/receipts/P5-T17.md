- **What changed:**
  - **The v1 transport (`apps/app/src/api/client.ts`):** `NOT_MODIFIED`, a unique symbol, and two request options. `ifNoneMatch` is sent as If-None-Match; a 304 to such a read is handed to `validate` as `NOT_MODIFIED` and returned, and a validator that does not take it refuses it (`invalid_response`). A 304 to any other read is still a refusal (`invalid`). `etag` hears a JSON success's ETag header, or null when it has none, only once the body passed `validate`; never a 304's or a refused body's.
  - **Resources (`apps/app/src/spend/v1/resources.ts`):**
    - `CreateEntryInput` and `CreateTransferInput` take a record's money keys (`currency`, `rate_source`, `rate`, `home_amount_minor`, `home_currency`, `trip_id`; a transfer also `to_amount_minor`), sent byte for byte. The phone sends none until P5-T21, and the outbox still refuses a draft holding one until P5-T18a.
    - `trips()`: GET `/v1/trips`, each trip checked by `isTripSnapshot`. `createTrip`: POST `/v1/trips`. `updateTrip` and `deleteTrip`: PATCH and DELETE `/v1/trips/:id` with If-Match. `tripSummary`: GET `/v1/trips/:id/summary`, checked by `isTripSummaryDto`.
    - `ratesToday(etag?)`: GET `/v1/rates/today` with If-None-Match when an ETag is given. It answers `'unchanged'` for a 304, else the set (checked by `isRatesTodayDto`) with the 200's own ETag, or null when it brought none.
    - `homeCurrencyPreview(currency)`: GET `/v1/me/home-currency/preview?currency=`, checked by `isHomeCurrencyPreview`. `setHomeCurrency(currency, version, commandId)`: PUT `/v1/me/home-currency` with `{ currency }`, and If-Match only when `version` is not null. Its acknowledgement is matched by its command, since the server derives the settings' id.
    - Every command carries its key and the command schema; a trip command's acknowledgement must be for its command and its trip; a malformed id is refused (`invalid`) before anything is sent.
  - **The rates cache (`apps/app/src/spend/v1/ratesCache.ts`, new, pure over a `KeyValueStore`):** `RATES_TODAY_NAME = 'rates-today'` (in the device store, `jotbun.wallet.rates-today`, so it leaves at sign-out with every device setting) and `CachedRates`. `readCachedRates` answers exactly `{ etag, rates }` or null: unreadable JSON, a store that cannot be read, extra keys, an ETag that is not text or null, or a set `isRatesTodayDto` refuses all read as none, never as a failure. `refreshRates` asks with the cached ETag; a new set is stored and answered, and `'unchanged'` or any failure answers the cache as it was and leaves it alone. It never rejects: a store that cannot be written still answers the new set.
  - **The fake (`apps/app/src/spend/v1/testing/fakeResources.ts`):** the eight methods in memory, each recorded in the call log.
    - Trips keep versions: 404, `ENTITY_DELETED`, and `VERSION_CONFLICT` with the current trip. No two live trips share a day, a touching day included: 422 `errors.trip_overlap` on `starts_on` for a create; for an edit on `ends_on` when only the end moves, else on `starts_on`. A deleted trip frees its days. The list is the live trips, the latest first.
    - The trip summary follows P5-T12's rules over the fake's live records tagged with the trip (X17): the count of every type; sums of expenses only; days ascending; categories by home amount, the larger first, then id; each distinct rate of a record in another currency, by date, then currency. A deleted or unknown trip is 404.
    - Today's rates: 503 `SERVICE_UNAVAILABLE` (retry 300) until `setRates(set)`, which gives each set a fresh ETag and returns it; `'unchanged'` for that ETag; `setRates(null)` clears it.
    - The home currency: `seed.settings` and `settings()`. A change must name the settings' version (null before the first change), else `VERSION_CONFLICT` with the current settings; the same currency is 422 `errors.home_currency_same` on `currency`; the id stays and the version moves. Records are not converted (C8 is the vault's, P5-T13). The preview counts every record the fake holds (none is purged), those at an own or exchange rate, and the budget months.
    - Its import of the transport names `client.ts`, so Node's test runner loads the fake.
