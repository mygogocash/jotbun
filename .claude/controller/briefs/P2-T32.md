## Planner rulings

- **P1. Extraction of `recapData.ts`.** Both `RecapScreen.tsx` and `WalletRecapScreen.tsx` need `useRecapData` and `shareText`. Extracting them to `recapData.ts` avoids code duplication, tracks analytics (`trackRecapOpened`, `trackRecapShared`), and keeps `RecapScreen.tsx` backwards-compatible (36/36 tests pass in `RecapScreen.render.test.tsx`).
- **P2. Test Assertion Rule (Controller rule).** RED must fail on assertions, never on lookups. `WalletRecap.render.test.tsx` defines `found`, `named`, `shown`, and asserts `expect(element, ...).not.toBeNull()`. When an element is missing in RED, it throws an `AssertionError`, NEVER a `TestingLibraryElementError`. In RED, exactly 11 tests fail, all 11 on `AssertionError`.
- **P3. Mutation Coverage.** Every guard in the implementation has a dedicated mutant in `tools/mutants.py`. That includes private mode masking (UI & share), number rules, date rules, tie-breaker, salary detection, cashback tips check, reduced motion & pending motion answer, empty state, and error/offline state. All 31 mutants are killed.
- **P4. Confetti and Haptic timing (R66).** First opening of a past month's recap plays celebration haptic and stores `jotbun.wallet.confetti-seen-{month}`. Confetti pieces render only if motion is fully known and reduced motion is false (`isReduced === false`). Under reduced motion or pending motion answer, celebration haptic plays once, but confetti pieces do not render.
- **P5. Private mode rules (D41, Review Focus 2).** In UI, `WalletAmount` masks values (`••••`). In share text (`recapShareText`), when `hidden: true`, all `฿` characters and all numeric monetary amounts (spent, budget, category totals) are strictly omitted.
- **P6. Share button copy.** Uses `t('recap.share')` (`แชร์สรุป`). It NEVER contains `การ์ด` (board wording violation).
- **P7. Catalogue sections.** Group is `'Kit'`. Specimen requires `label`. Four sections: `bw-recap`, `bw-recap-over`, `bw-recap-private`, `bw-recap-cashback`.
- **P8. Merge compatibility.** `index.ts` conflict resolution with P2-T14 and P2-T33 is proven in `PL/merge/`.
