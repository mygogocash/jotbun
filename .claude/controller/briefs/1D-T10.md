## What the code does (for reading; the files are the spec)

- **The Worker** (`handleVaultV1`): the route `GET /v1/sync/live` (`access: 'bound_session'`, `live: true`, no gate) runs every check a vault route runs (route, body, gates, client version, token). Then, in place of the vault call, `openLiveSocket` answers 400 `VALIDATION_FAILED` unless `upgrade` is `websocket` in any case (never 426, which the app reads as "update the app"), and otherwise returns `stub.fetch(liveRequest(claims))` unchanged: a fresh `GET https://vault.internal/live` whose only claim carrier is `x-vault-claims` (every `VaultClaims` field as JSON). The token never reaches the vault.
- **`UserVault#fetch`**: 404 unless it is that GET with the upgrade. An erased instance answers 403 `ACCOUNT_UNAVAILABLE` before it reads a table. Claims that do not parse (`parseLiveClaims`: UUID account and session, integer `issuedAt`, non-empty `clientId`, integer `authTime` when present) are 400. Then one `transactionSync` runs `call()`'s checks in `call()`'s order: `ensureAccount`, the `principal` charge, `assertSession`, the `read` charge. A refusal is the v1 problem JSON with its status (`liveRefusal`) and never upgrades. Only then `acceptLive`: this session's earlier sockets close with 4409; the new one is accepted with the tag `[sessionId]` and the attachment `{ sessionId, issuedAt, openedAt }`; while more than 20 are open, the oldest open socket of another session, by `openedAt`, closes with 4409 (a closing socket does not count).
- **After every call and alarm** (`afterCall`, which is `afterVaultWork`): `before` is read outside the block; in a `finally`, `after` is read and, when `BigInt(after) > BigInt(before)`, every socket but the caller's session gets `{"revision":"<after>"}` (the alarm excepts no session); then `closeEndedSessions(state, sql, false)` closes with 4401 every socket of an account that is not active, and those whose token's `iat` is before `not_before` or whose session is in `revoked_sessions` (one query, the ids as one JSON parameter, R57). It never throws: a failure is logged as `live_after_call_failed` with the failure's class name only.
- **Messages**: the constructor sets the `ping`/`pong` auto-response, which never wakes the vault. `webSocketMessage` closes with 1008 whatever reaches it. `webSocketClose` answers the phone's close (deviation 1 below). `webSocketError` does nothing.

## Deviations the planner made, with evidence (record them in your receipt)

1. **`webSocketClose` answers the phone's close** with `ws.close(code, reason)` (or 1000 when that code cannot be sent back) instead of doing nothing. The plan relies on the runtime answering a Close frame itself from compatibility date 2026-04-07. The workerd these tests run (1.20261019.1, `wrangler.vault.jsonc` compatibility date 2026-10-01) does not: without a reply in the vault, a phone's close never completed (`PL/logs/probe-close.log`: still `open` after 1.5 seconds); with the reply, the vault's handler ran with the socket in CLOSING (readyState 2) and the phone's close event came at once (`PL/logs/probe-close2.log`). Cloudflare's WebSocket page says calling `close()` in the handler stays safe under the new behaviour. Mutant M10 pins it.
2. A refused open is built in the vault as the v1 problem (`problemResponse`, with the vault's own request id), and the Worker returns it unchanged, as the plan says.
3. A missing or malformed `x-vault-claims` is 400; only a wrong method, URL or a missing upgrade is 404.
4. `live.ts` exports more than the plan's list, so the vault and the Worker share one definition of each: `LIVE_VAULT_URL`, `closeSocket`, `afterVaultWork`, `wantsWebSocket`, `liveRequest`, `isLiveRequest`, `liveClaimsOf`, `liveRefusal`. `UserVault#afterCall` keeps the plan's private signature and calls `afterVaultWork`.
5. `cloudflare-workers.d.ts` does not redeclare `readyState`: the DOM's `WebSocket` has it.
6. Tests. The plan's "A has received nothing 200 ms later" uses no wait: A pings, and its pong comes after anything the vault sent it first. Beyond the plan: 9 to 10 is a poke (BigInt, not text); a phone's own close is answered; a send to a closing socket is skipped and the loop goes on; `closeEndedSessions` with `erased`; only the Worker's internal request reaches the checks, with `parseLiveClaims`' cases; a socket closing in the same turn does not count toward 20; the read budget bounds opens (429 after 120 a minute). The erased case also deletes the marker row: with the marker in place `ensureAccount` answers the same 403, so the plan's mutant "check erased after ensureAccount" would survive (its "500, the tables are gone" predates 1B-T2's marker).
7. The runtime drops a closed socket from `getWebSockets()` at once (`PL/logs/probe-close.log` and `probe-close3.log`), so in the plan's 20-socket scenario a socket the phone closed is not listed either way. That case keeps the plan's assertion; the "a closing socket does not count" rule is pinned by the same-turn case (M6).

## R78 and R86: what the live channel does with them (no change in this task)

- The vault binds each socket to the token's `sid` (R78). A phone's writes and its socket must therefore carry the same session, or the saving phone would hear its own poke and a sign-out would close the wrong socket.
- 1C-T5 (R86) hands a token out only when its `sid` is the session the provider holds, and returns null while it is not ready. The phone's live channel (1D-T5) already reads its token through `v1SessionCredentials.getAccessToken()` at every (re)connect, never caches it and sends no session header, so once 1C-T5 merges the socket and the phone's requests carry one session with no further change.
- What the channel must keep doing: read the token only through `V1Credentials.getAccessToken()` at each connect; on null connect nothing; on a rejection retry after its backoff; on 4401 run one live flush and stop, so the next request meets the sign-out (D37).
- Gap for the integrator, not for this task: on a null token the channel waits for its next `start()` (launch or foreground), so after a sign-in finishes the socket opens at the next foreground; the other sync fallbacks still run. Restarting the channel on a session change belongs to 1C-T5's merge or 1D-T12/T15.

```ts
/**
 * Opens GET /v1/sync/live as the phone does: the token and client headers that
 * `client.as(user)` sends, and `upgrade: websocket`. On 101 the test accepts the
 * socket and records its messages (Cloudflare's testing-with-durable-objects
 * pattern); otherwise it gets the status and the JSON body.
 */
export async function openLive(client: V1Client, user: TestUser, opts: { client?: string } = {}): Promise<{ status: number; body?: unknown; socket?: LiveTestSocket }> {
  const headers = { ...(await signedHeaders(user, { client: opts.client })), upgrade: 'websocket' }
  const res = await client.raw(new Request(`${BASE}/v1/sync/live`, { headers }))
  const ws = res.webSocket
  if (res.status !== 101 || !ws) return { status: res.status, body: await res.json().catch(() => undefined) }

function recordedSocket(ws: WebSocket): LiveTestSocket {
  const messages: string[] = []
  const waiting: { resolve: (message: string) => void; reject: (error: Error) => void }[] = []
  let taken = 0
  let ended = false
  let markClosed: (closed: { code: number }) => void = () => undefined
  const closed = new Promise<{ code: number }>((resolve) => {
    markClosed = resolve
  })
  ws.addEventListener('message', (event) => {
    const message = typeof event.data === 'string' ? event.data : '<binary>'
    messages.push(message)
    const waiter = waiting.shift()
    if (waiter) {
      taken += 1
      waiter.resolve(message)
    }
  })
  ws.addEventListener('close', (event) => {
    ended = true
    markClosed({ code: event.code })
    for (const waiter of waiting.splice(0)) waiter.reject(new Error(`the socket closed with ${event.code} before another message`))
  })
  return {
    messages,
    next(timeoutMs = 2_000) {
      if (taken < messages.length) return Promise.resolve(messages[taken++])
      if (ended) return Promise.reject(new Error('the socket is closed'))
      return new Promise<string>((resolve, reject) => {
        const waiter = {
          resolve: (message: string) => {
            clearTimeout(timer)
            resolve(message)
          },
          reject: (error: Error) => {
            clearTimeout(timer)
            reject(error)
          },
        }
        const timer = setTimeout(() => {
          waiting.splice(waiting.indexOf(waiter), 1)
          reject(new Error(`no message within ${timeoutMs} ms`))
        }, timeoutMs)
        waiting.push(waiter)
      })
    },
    closed,
    send: (data) => ws.send(data),
    close: () => {
      try {
        ws.close(1000)
      } catch {
        // Already closed.
      }
    },
  }
}
```

```ts
// Live pokes (1D-T10, spec §6.5, plan 1D's L1 and L2). The vault holds each
// phone's socket with the WebSocket Hibernation API, so a vault with open
// sockets still sleeps. After every call and alarm it compares the revision:
// when a block committed, every other session hears {"revision":"<n>"} and
// pulls through its ordinary sync. Sockets never carry record data: the vault
// sends only that poke, the runtime answers `ping` with `pong`, and the phone
// sends nothing else. After every call, whatever its outcome, the sockets whose
// session has ended close with 4401. A send or close that throws (a socket
// already closing) is skipped, and the loop goes on.
import type { DurableObjectStateLike } from 'cloudflare:workers'

import { isUuid } from '@gogospend/contracts'

import { ProblemException } from '@api/common/api-problem.filter'

import { problemResponse } from '../server/http/problem'
import { logFailure } from '../v1/log'
import type { VaultClaims, VaultReply } from '../v1/protocol'
import { toProblemReply } from './replies'

/** What a socket keeps through hibernation: its session, its token's iat (epoch seconds) and when it opened (the vault clock, epoch ms). */
export type LiveAttachment = { sessionId: string; issuedAt: number; openedAt: number }

/** 4401: the session ended. 4409: a newer socket took its place. 1008: the phone sent something other than ping. */
export const LIVE_CLOSE = { sessionEnded: 4401, replaced: 4409, unexpected: 1008 } as const

/** At most this many sockets are open in one vault; past it the oldest open one closes with 4409. */
export const MAX_LIVE_SOCKETS = 20

/** The internal request the Worker hands the vault. The object has no public route, so only the Worker can build it. */
export const LIVE_VAULT_URL = 'https://vault.internal/live'

/** The one header that carries the verified claims to the vault. The token never reaches it. */
const CLAIMS_HEADER = 'x-vault-claims'

/** The account's revision as text, '0' before the account exists. Compared as BigInt, never as a number. */
export function currentRevision(sql: SqlStorage): string {
  return sql.exec<{ revision: string }>('SELECT CAST(revision AS TEXT) AS revision FROM sync_state WHERE id = 1').toArray()[0]?.revision ?? '0'
}

/** The only message the vault sends: the new revision, and nothing of the record. */
export function pokeMessage(revision: string): string {
  return JSON.stringify({ revision })
}

/** Closes a socket. One that is already closing throws, and is skipped. True when this call closed it. */
export function closeSocket(ws: WebSocket, code: number, reason: string): boolean {
  try {
    ws.close(code, reason)
    return true
  } catch {
    return false
  }
}

function attachmentOf(ws: WebSocket): LiveAttachment | null {
  try {
    const value = ws.deserializeAttachment() as LiveAttachment | null
    return value !== null && typeof value === 'object' && typeof value.sessionId === 'string' ? value : null
  } catch {
    return null
  }
}

/** Sends the poke to every socket whose session is not `exceptSession`. A send that throws is skipped. Returns how many were sent. */
export function pokeOthers(state: DurableObjectStateLike, revision: string, exceptSession: string | null): number {
  const message = pokeMessage(revision)
  let sent = 0
  for (const ws of state.getWebSockets()) {
    if (exceptSession !== null && state.getTags(ws).includes(exceptSession)) continue
    try {
      ws.send(message)
      sent += 1
    } catch {
      // Already closing: skipped.
    }
  }
  return sent
}

/**
 * Closes, with 4401, every socket whose session has ended. With `erased`, every
 * socket closes and no table is read. Otherwise an account that is not active
 * (or missing) closes every socket, and an active one closes the sockets whose
 * token was issued before `not_before` or whose session was signed out. The
 * signed-out check is one query with the session ids bound as one JSON
 * parameter (R57). Returns how many closed.
 */
export function closeEndedSessions(state: DurableObjectStateLike, sql: SqlStorage, erased: boolean): number {
  const sockets = state.getWebSockets()
  if (sockets.length === 0) return 0
  let ended: (attachment: LiveAttachment | null) => boolean = () => true
  if (!erased) {
    const [account] = sql.exec<{ status: string; not_before: number }>('SELECT status, not_before FROM account_state WHERE id = 1').toArray()
    if (account?.status === 'active') {
      const ids = [...new Set(sockets.flatMap((ws) => attachmentOf(ws)?.sessionId ?? []))]
      const revoked = new Set(
        sql
          .exec<{ session_id: string }>('SELECT session_id FROM revoked_sessions WHERE session_id IN (SELECT value FROM json_each(?))', JSON.stringify(ids))
          .toArray()
          .map((row) => row.session_id),
      )
      ended = (attachment) => attachment === null || attachment.issuedAt < account.not_before || revoked.has(attachment.sessionId)
    }
  }
  let closed = 0
  for (const ws of sockets) {
    if (ended(attachmentOf(ws)) && closeSocket(ws, LIVE_CLOSE.sessionEnded, 'session ended')) closed += 1
  }
  return closed
}

/**
 * After a call or an alarm (L2): pokes every session but `exceptSession` when
 * the revision grew past `before` (only a committed block moves it), then
 * closes the sockets whose session has ended, whatever the outcome. Never
 * throws: a failure is logged, and the reply goes back unchanged.
 */
export function afterVaultWork(state: DurableObjectStateLike, before: string, exceptSession: string | null): void {
  try {
    const sql = state.storage.sql
    const after = currentRevision(sql)
    if (BigInt(after) > BigInt(before)) pokeOthers(state, after, exceptSession)
    closeEndedSessions(state, sql, false)
  } catch (error) {
    logFailure('live_after_call_failed', error)
  }
}

/** The claims the Worker wrote, every VaultClaims field checked: UUID account and session ids, an integer iat, a client id, and an integer auth_time when present. Anything else is null. */
export function parseLiveClaims(header: string | null): VaultClaims | null {
  if (header === null) return null
  let value: unknown
  try {
    value = JSON.parse(header)
  } catch {
    return null
  }
  if (typeof value !== 'object' || value === null || Array.isArray(value)) return null
  const { accountId, sessionId, issuedAt, clientId, authTime } = value as Record<string, unknown>
  if (typeof accountId !== 'string' || !isUuid(accountId) || typeof sessionId !== 'string' || !isUuid(sessionId)) return null
  if (typeof issuedAt !== 'number' || !Number.isInteger(issuedAt)) return null
  if (typeof clientId !== 'string' || clientId.length === 0) return null
  if (authTime !== undefined && (typeof authTime !== 'number' || !Number.isInteger(authTime))) return null
  return authTime === undefined ? { accountId, sessionId, issuedAt, clientId } : { accountId, sessionId, issuedAt, clientId, authTime }
}

/** True when the request asks for a WebSocket (`upgrade: websocket`, in any case). */
export function wantsWebSocket(request: Request): boolean {
  return request.headers.get('upgrade')?.toLowerCase() === 'websocket'
}

/** The Worker's request to the vault: the internal URL, the upgrade and the verified claims, and nothing else. */
export function liveRequest(claims: VaultClaims): Request {
  return new Request(LIVE_VAULT_URL, { headers: { upgrade: 'websocket', [CLAIMS_HEADER]: JSON.stringify(claims) } })
}

/** The only request UserVault#fetch serves: a GET of the internal URL that asks for a WebSocket. */
export function isLiveRequest(request: Request): boolean {
  return request.method === 'GET' && request.url === LIVE_VAULT_URL && wantsWebSocket(request)
}

/** The claims of a live request. An erased vault refuses first (403), before it reads a table; claims that do not parse are 400. */
export function liveClaimsOf(request: Request, erased: boolean): VaultClaims {
  if (erased) throw new ProblemException(403, 'ACCOUNT_UNAVAILABLE')
  const claims = parseLiveClaims(request.headers.get(CLAIMS_HEADER))
  if (!claims) throw new ProblemException(400, 'VALIDATION_FAILED')
  return claims
}

/** A refused open: the problem toProblemReply makes of the error, as v1 JSON with its status. It never upgrades. */
export function liveRefusal(error: unknown): Response {
  const reply = toProblemReply(error) as Extract<VaultReply, { ok: false }>
  return problemResponse(reply.status, reply.code, crypto.randomUUID(), reply.problem)
}

/**
 * Accepts the socket of a session whose checks passed: its earlier sockets
 * close with 4409, the new one is accepted with the tag [sessionId] and its
 * attachment, and while more than MAX_LIVE_SOCKETS are open the oldest open
 * one, by openedAt, closes with 4409. A closing socket does not count.
 */
export function acceptLive(state: DurableObjectStateLike, claims: VaultClaims, nowMs: number): Response {
  for (const old of state.getWebSockets(claims.sessionId)) closeSocket(old, LIVE_CLOSE.replaced, 'replaced')
  const pair = new WebSocketPair()
  const client = pair[0]
  const server = pair[1]
  state.acceptWebSocket(server, [claims.sessionId])
  const attachment: LiveAttachment = { sessionId: claims.sessionId, issuedAt: claims.issuedAt, openedAt: nowMs }
  server.serializeAttachment(attachment)
  const others = state
    .getWebSockets()
    .filter((ws) => ws.readyState === WebSocket.OPEN)
    .map((ws) => ({ ws, openedAt: attachmentOf(ws)?.openedAt ?? 0, sessionId: attachmentOf(ws)?.sessionId }))
    .filter((open) => open.sessionId !== claims.sessionId)
    .sort((a, b) => a.openedAt - b.openedAt)
  let excess = others.length + 1 - MAX_LIVE_SOCKETS
  for (const { ws } of others) {
    if (excess <= 0) break
    if (closeSocket(ws, LIVE_CLOSE.replaced, 'too many sockets')) excess -= 1
  }
  return new Response(null, { status: 101, webSocket: client })
}
```

```ts
describe('limits', () => {
  it('only open sockets count toward 20', async () => {
    const a = await member(client)
    const t0 = Date.now()
    const sockets: LiveTestSocket[] = []
    for (let i = 0; i < 20; i += 1) {
      await setClock(a, t0 + i * 1_000)
      sockets.push(await live(otherSession(a)))
    }
    // The newest phone closes its own socket; once closed it no longer counts.
    sockets[19].close()
    expect(await closeCode(sockets[19])).toBe(1000)
    for (let i = 20; i < 22; i += 1) {
      await setClock(a, t0 + i * 1_000)
      sockets.push(await live(otherSession(a)))
    }
    expect(await closeCode(sockets[0])).toBe(4409)
    for (const socket of [...sockets.slice(1, 19), ...sockets.slice(20)]) await pong(socket)
  })

  it('a socket that is closing does not count toward 20', async () => {
    const a = await member(client)
    const t0 = Date.now()
    const sessions = Array.from({ length: 20 }, () => otherSession(a))
    const sockets: LiveTestSocket[] = []
    for (const [i, session] of sessions.entries()) {
      await setClock(a, t0 + i * 1_000)
      sockets.push(await live(session))
    }
    const newcomer = otherSession(a)
    const oldest = await runInDurableObject(vaultOf(a), (_v, state) => {
      // The newest socket starts closing in this same turn: still listed, no longer open.
      for (const ws of state.getWebSockets(sessions[19].sid)) ws.close(1000, 'closing')
      acceptLive(state, { accountId: a.sub, sessionId: newcomer.sid, issuedAt: Math.floor(t0 / 1000), clientId: 'ios/1.0.0' }, t0 + 30_000)
      const readyState = state.getWebSockets(sessions[0].sid)[0]?.readyState
      for (const ws of state.getWebSockets(newcomer.sid)) ws.close(1000, 'done')
      return readyState
    })
    expect(oldest).toBe(WebSocket.OPEN)
    await pong(sockets[0])
  })

  it("opening a socket spends the session's read budget: past 120 a minute it is 429 and nothing upgrades", async () => {

    let latest: LiveTestSocket | undefined

    await pong(latest as LiveTestSocket)
  })
```
