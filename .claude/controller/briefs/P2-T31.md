## Planner rulings

- **P1. Motion (W6, R66).** The insights screen contains no custom animations or moving elements. Motion in `InfoTray` delegates to `Tray` which reads `useWalletReducedMotion()`. Under Reduce Motion, nothing moves.
- **P2. Failure handling and localized error presentation.** All load failures in `useInsightsData` are passed through `recapProblem(error, tc)`. In error state, `WalletInsightsScreen` renders `Notice` with `Try again` reload button, and displays `SyncBanner` when offline.
- **P3. Catalogue sections lazy loading.** `insightsSections.tsx` lazy-loads `SpendingTab`, `InOutTab`, and `CalendarTab` using React `lazy` and `Suspense`. This ensures `expo-router` is never loaded at registry evaluation time, preserving full compatibility with `walletHarness.render.test.tsx`.
- **P4. Complete data reads without early stops.** `useInsightsData` reads `resources.summary(month)`, `resources.categories()`, all 6 comparison months' summaries, and reads every page of the month's history using `readAllPages` (cursor-based until `next_cursor` is null).
- **P5. Colour and type from kit with zero raw hex.** No implementation file uses raw `#` hex colors. All palette tokens come from `useWalletColors()` (`ink`, `ground`, `card`, `raised`, `quiet`, `hairline`, `violet`, `barNow`, `barPast`, `guideLine`) and `calendarPaint(step, isDark)`. Typography uses `WalletText` and `WalletAmount`. Verified in light and dark mode.
- **P6. Copy is Thai first.** Every user-visible line is stored in `COPY` in `copy.ts` and read via `useDraftCopy(COPY)`. Thai lines are standard; English lines are drafts for E2-B.
- **P7. Private mode masking (R65).** In private mode (`hidden: true`):
  - In `MonthBars`, the chart's accessibility label includes only the chart title and month names (e.g. `ใช้จ่ายรายเดือน พฤษภาคม 2569ถึงตุลาคม 2569: พฤษภาคม 2569, ...`), strictly omitting all monetary numbers and `฿` / `บาท`. The budget line is masked (`฿••••`).
  - In `CalendarTab`, every day button uses neutral fill `raised` (`#F4F3F9` in light mode), day amounts are omitted, the month line amount is masked (`฿••••`), and the legend shows swatches without monetary labels.
  - In `InOutTab`, the kept banner masks amount (`฿••••`), and hero amounts mask via `WalletAmount`.
  - Tested in both Thai and English.
- **P8. 44 pt controls and no clamped text.** Tabs have `minHeight: 44` (`role="tab"`). Calendar day buttons have `minHeight: 50`. Calendar prev/next buttons have 44x44 pt hit targets. Info button has a 44x44 pt hit target. Category rows have `minHeight: 48`. No text elements use `numberOfLines`.

Test Assertion Rule (Controller rule).** RED must fail on assertions, never on lookups. `WalletInsights.render.test.tsx` defines asserting helpers `found`, `named`, and `shown` which query elements and assert `expect(element).not.toBeNull()`.
