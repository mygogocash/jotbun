- **What changed:**
  - Apple (P5): offered on iOS only (K15). Its availability is checked first: `isAvailableAsync()` answering false is a refusal, so the port's `methods` stay synchronous. Only the email scope is requested. One fresh `Crypto.randomUUID()` nonce per sign-in goes to Apple and comes back with the token. Apple's `authorizationCode` is returned with the token for 1C-T13, and left out (not `null`) when absent. A closed sheet (`ERR_REQUEST_CANCELED` on the error's `code`) is `AuthCancelled`. No `identityToken` is `AuthRefused('REFUSED')`. Any other failure passes through unchanged.
  - Google (P6): offered only with its web client id, and on iOS only with its iOS client id as well (P6 (a)). It is configured once, at the first sign-in, with the ids that are set. On Android, Play services are asked first; a `false` answer is a refusal, and a rejection passes through as a failed sign-in (P6 (c)). A cancelled response is `AuthCancelled`, and a response without an ID token is `AuthRefused('REFUSED')`. No nonce goes to Google (P6 (d)).
  - Loading (P7): `nativeModules.ts` imports Apple's module at the top. It is Expo's own and does not throw while loading. Google's module is loaded once, with `import()`, at its first Google call (memoised), and is configured as it loads. With the ids unset, Google is never offered, so its module never loads.
  - `nativeModules.web.ts` answers `NO_NATIVE_SIGN_IN` (P10).
  - `env.ts` reads `EXPO_PUBLIC_GOOGLE_WEB_CLIENT_ID` and `EXPO_PUBLIC_GOOGLE_IOS_CLIENT_ID`, trimmed; both default to `''`.
  - `app.config.js` (P9): `withNativeSignIn(config)` sets `ios.usesAppleSignIn` and appends `expo-apple-authentication` after `config.plugins`, which is app.json's list as Expo reads it, so the file never copies that list by hand. It appends Google's plugin with `{ iosUrlScheme }` only when `EXPO_PUBLIC_GOOGLE_IOS_URL_SCHEME` is set, trimmed. `app.json` does not change.
  - `betterAuthClient.ts` passes `appNativeSignIn()` from `./nativeModules`, and its doc line now says Apple's sheet on iOS and Google's once the build has its ids.
