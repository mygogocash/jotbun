Sign out everywhere, account deletion and export now run a fresh sign-in with the account's own method first, then go on that new session's own credentials (no purpose proof): sign out everywhere through the Better Auth port; deletion with today's body `{ proof_id }` (a random UUID), the command id as the key, and the app's language as `Accept-Language` (the receipt token-only with the request's own token); export with `{ proof_id, from, through }`. A fresh sign-in that does not go through sends nothing. `reauthentication.ts` is gone. Settings and Privacy keep their states and words; on this build no method has a fresh sign-in yet, so both keep their disabled reasons.
