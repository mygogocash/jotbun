- **Delivers:** H5, B5 as A14 refines it. A use is still counted before the first model call. When the request ends without a model answer (the rules, the plain facts or 503) and its last call failed with a rate limit, a 5xx, a timeout or no connection, the use goes back to the Bangkok day it was counted on, before the route answers. A decline, an unusable or ungrounded answer, a request the API rejected and any other failure spend it.
